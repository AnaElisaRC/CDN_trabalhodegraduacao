# 🎓 Trabalho de Graduação (TG) — Ciência de Dados para Negócios

Este repositório reúne toda a documentação, versões de escrita e materiais complementares do Trabalho de Graduação (TG) do curso de **Tecnologia em Ciência de Dados para Negócios** da **FATEC Votorantim**.

O trabalho consiste na síntese e evolução dos **Projetos Integradores (PIs)** desenvolvidos ao longo do curso, consolidando a aplicação prática da Ciência de Dados na resolução de problemas de negócios.

📌 Conteúdo e Etapas
Manual do TG (Manual_TG_CDN_v1-3_revisada.pdf): Documento com as orientações, formatação (ABNT) e requisitos de entrega estabelecidos pela coordenação.

Evolução do Documento (TG.*.docx): Histórico de versões da escrita da monografia/artigo, demonstrando as iterações de desenvolvimento e correções.

Submissão para Simpósio (Simpósio/): Arquivos relativos à publicação e apresentação do trabalho em simpósio acadêmico de Ciência de Dados.
